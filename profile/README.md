# Advens

Code we like and choose to publish.

## Published

| Project | What it is |
|---------|------------|
| [libsigma](https://github.com/advens/libsigma) | C11 compiled Sigma matcher and in-process correlator. No YAML at match time. |
| [libwake](https://github.com/advens/libwake) | C library for a distributed detection mesh. |
| [libenrich](https://github.com/advens/libenrich) | One command and one config to build threat, context, GeoIP, user-agent, and suffix feeds. |
| [Z-Attack](https://github.com/advens/Z-Attack) | Z-Wave packet interception and injection. |

Upstream work (rsyslog, liblognorm, and the rest) stays in those projects.
This org is Advens-originated code only.

## Contribute
